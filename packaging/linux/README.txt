LingQ Prep
==========

LingQ Prep prepares ebooks (EPUB) for importing into LingQ.

Try it without installing
-------------------------
Double-click "lingqprep". If nothing happens, right-click it, open
Properties and allow it to run as a program (it may also be called
"Executable as Program"), then double-click it again.

Install it
----------
Right-click in an empty spot of this folder, choose "Open in Terminal",
type the following and press Enter:

    ./install.sh

LingQ Prep is then in your app menu, and this folder can be deleted.
The "lingqprep" command also works in a terminal: run "lingqprep -h"
to see how.

Uninstall it
------------
Run ./uninstall.sh the same way.
